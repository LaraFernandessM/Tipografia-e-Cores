# 🎨 Tipografia e Cores
Este documento apresenta o guia visual do projeto, definindo as cores principais da identidade visual e os padrões de tipografia utilizados na interface.

# ✨ Contraste

O projeto também apresenta uma organização de contraste aplicada aos diferentes níveis tipográficos, utilizando a mesma escala de tamanhos:

<p>Small: 14px</p>
<p>Parágrafo: 16px</p>
<p>H5: 18px</p>
<p>H4: 24px</p>
<p>H3: 28px</p>
<p>H2: 34px</p>
<p>H1: 40px</p>

# 📍Objetivo

O objetivo é manter uma padronização tipográfica em todo o projeto, facilitando a leitura e criando uma hierarquia clara entre os diferentes elementos de texto.

# 📰 Fonte

A fonte utilizada no projeto é a Poppins.

# 📋 Resumo
<p>Categoria - Definição</p>
<p>Fonte	--  Poppins</p>
<p>Menor -- tamanho	14px</p>
<p>Texto -- padrão	16px</p>
<p>Maior -- tamanho	40px</p>
<p>Níveis de título -- H1, H2, H3, H4 e H5</p>
<p>Objetivo -- Padronização e hierarquia visual</p>
